# Telegram chat edit

**Job:** send a clip in Telegram, get a real edit back. Open the same timeline in the browser if a cut is wrong.

This is chat, not MCP. Open [@vidmoat_bot](https://t.me/vidmoat_bot).

```
Send the clip to @vidmoat_bot with a caption:

cut the silence and add captions
```

Or:

```
cut the ums and dead air
```

Technique:

- Leave 150–300ms of pad on each cut. Do not cut on dB alone.
- Preview frames as images if a caption might sit on a mouth. Move it.
- Then render.

If the cut is too tight, open the same project at [vidmoat.com](https://vidmoat.com) and restore the beat. The Telegram file is not a flattened black box.
