# Podcast to shorts

**Job:** one long episode → 8–12 vertical clips, karaoke captions, hooks rewritten.

Paste after the episode is in a Vidmoat project (web upload, desktop, or MCP import).

```
This project is a podcast episode. Transcribe it.

Pick 10 self-contained moments that would work as 30–55 second TikToks. For each: start and end timestamps, a one-line hook, and why it stands alone (no "as I said earlier").

For the best 8:
1. Cut that range into its own sequence.
2. Reframe 9:16 and keep the speaker in frame.
3. Add karaoke captions, 4–6 words on screen, brand-neutral.
4. Write a hook title on the first 1.5 seconds.
5. Preview 3 frames per clip as images.
6. Fix captions on faces, then render each clip 1080x1920.

Do not flatten the timeline. I will still grab a playhead.
```

Follow-up if it over-cuts:

```
Restore 200ms of pre-roll before each hook so the first word is not clipped. Re-preview the first frame of each short.
```
